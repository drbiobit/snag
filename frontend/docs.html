Snag exposes a small JSON API. Start a download, then poll its status until it finishes. All request and response bodies are JSON. Click any code block to copy it.

POST /api/validate

Check whether a string is a valid YouTube URL and whether it points at a collection (bulk).

request body

{
  "url": "https://www.youtube.com/watch?v=dQw4w9WgXcQ"
}

response · 200

{
  "valid": true,
  "url": "https://www.youtube.com/watch?v=dQw4w9WgXcQ",
  "bulk": false
}
POST /api/download

Start a download. Returns a job_id you can use to poll status or cancel. Enforces a limit of 2 concurrent downloads.

request body

{
  "url": "https://www.youtube.com/watch?v=...",
  "type": "video",              // video | bulk | mp3
  "format": "best",             // best | 1080 | 720 | 480 | audio | video
  "audio_only": false,
  "audio_format": "mp3",        // mp3 | m4a | wav | ogg | flac
  "audio_quality": 2,           // 0=vbr 1=128k 2=192k 3=256k 4=320k
  "output_format": "mp4",       // mp4 | webm | mkv | mov
  "output_template": "",        // single downloads only, e.g. %(title)s.%(ext)s
  "resume": true,
  "fragments": 0,               // 0=off 2/4/8/16 concurrent fragments
  "metadata": false             // embed tags/thumbnail/chapters (off by default)
}

response · 200

{
  "success": true,
  "job_id": "1712345678901"
}

errors

400 { "success": false, "error": "Invalid YouTube URL" }
429 { "success": false, "error": "Too many concurrent downloads" }
GET /api/status/<job_id>

Poll the progress and status of a running job. status is one of pending, completed, error, cancelled.

response · 200

{
  "success": true,
  "job": {
    "id": "1712345678901",
    "url": "https://www.youtube.com/watch?v=...",
    "status": "pending",
    "progress": 42.5,
    "message": "Downloading... 42%",
    "started_at": "2026-10-01T12:00:00",
    "cancelled": false
  }
}

errors

404 { "success": false, "error": "Job not found" }
POST /api/cancel/<job_id>

Flag a running job so its worker thread stops yt-dlp. The job's status becomes cancelled.

response · 200

{
  "success": true,
  "job_id": "1712345678901"
}

errors

404 { "success": false, "error": "Job not found" }
GET /api/downloads

List all files currently in the downloads folder with their sizes.

response · 200

{
  "success": true,
  "downloads": [
    { "name": "Some Video.mp4", "size": 13290030 }
  ]
}

fieldvaluesnotes

audio_onlytrue · falseextract audio instead of video

audio_quality0 · 1 · 2 · 3 · 40=vbr, 1=128k, 2=192k, 3=256k, 4=320k
